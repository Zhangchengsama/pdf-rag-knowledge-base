- src：原 v6 当前源码；tests：原测试与评测资料；docs：说明文档。
- legacy：原样保留 v1、v2、v3、v3 weight_rrf、v4、v5。

- 迁移逐文件核对，未删除任何文件或目录。外部默认教材及原缓存保留，复制的四份缓存合计 636526 字节。运行数据不进入 Git。

- 整理前 77 项测试通过；第一步完成后 78 项通过；最终 85 项离线测试全部通过。

- 12 个切块、编码、检索、融合、提示词、模型、消息与锁模块与原版本内容一致（比较忽略 Git 换行格式）。34 个当前 Python 文件通过语法检查。
- 新旧缓存路径返回相同的离线回答与来源；覆盖缓存复用、实际页数变化、失败重试沿用原资料、上传和设置持久化。
